Talk while you record

Say what you are checking as you go — “now I’m checking that this order needs manager approval” — and it becomes the expected result, instead of the tool guessing which of the changes on screen mattered.

Chrome will ask for the microphone once. After that it never asks again.

What happens to the audio. It is saved with the recording on your own machine and transcribed there. It is not uploaded anywhere — the aitc-rem server runs on 127.0.0.1.

The recording is kept so you can play back what you actually said. Speech is transcribed, not read, and a mis-heard number is the one thing no automatic check here can catch. Anything you say out loud is written down, so treat it the way you would treat typing into the page.
